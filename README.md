# 🍽️ Restoran - Responsive Restaurant Website

A modern, responsive, and visually appealing restaurant landing page built with pure web technologies. This website features a dynamic user interface, smooth navigation, and a multi-language switcher.

👉 **Live Demo:** [https://restoran-web-ten.vercel.app/](https://restoran-web-ten.vercel.app/)

---

## 🌐 Language Options / Pilihan Bahasa

This project supports bilingual content to cater to a wider audience:
* 🇬🇧 **English** (Default View)
* 🇮🇩 **Indonesian**

---

## ✨ Features / Fitur Utama

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
* **Multi-Language Support:** Dynamic language switching between English and Indonesian using JavaScript.
* **Interactive Components:**
  * Dropdown menu for language selection.
  * Smooth scrolling navigation.
  * "Book a Table" call-to-action buttons.
  * Back-to-top quick navigation button.
* **Modern UI/UX:** Clean typography with a vibrant food-themed color palette.

---

## 🛠️ Tech Stack / Teknologi yang Digunakan

This project is built from scratch without heavy frameworks, focusing on performance and clean native code:

* **HTML5:** Semantic structuring of the web layout.
* **CSS3:** Custom styling, layout positioning, and responsive media queries.
* **Vanilla JavaScript:** Logic for the multi-language toggler and interactive UI elements.
* **Vercel:** Cloud platform used for quick production deployment.
